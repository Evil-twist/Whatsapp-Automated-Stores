# Whatsapp-Automated-Stores - Bulk Business Website Templates
A Catalog of an automated e-commerce and ordering stores built for SMEs or businesses who takes whatsapp orders.

13+ Ready-to-Use Business Websites with Landing Page + Admin Panel + WhatsApp Auto-Order System.

No payment gateway. No cart complexity. Customers order directly via WhatsApp in 1 click.

### How It Works

**Customer Flow:**
1. Customer opens landing page (e.g., `shoes biz/index.html`)
2. Browses products/services, prices, images
3. Clicks `Order on WhatsApp` / `Book Now`
4. System auto-generates a WhatsApp message: 
   `Hello, I want to order: Nike Air Max - Size 42 - GHS 350 - Qty: 1`
5. Message opens in WhatsApp to the business number instantly.

**Business Owner Flow:**
1. Opens `/admin` page for their store
2. Adds/Edits/Deletes products, prices, and images
3. Receives orders directly on WhatsApp
4. Manages everything without coding.

### Features

**1. Landing Page (Customer Side):**
- Fully responsive (mobile-first)
- Product grid with images, prices, descriptions
- WhatsApp floating button + direct order buttons
- Business info, location, opening hours, social links
- Call-to-action optimized for conversions

**2. Admin Page (Business Owner Side):**
- Simple login protected admin dashboard
- Add, edit, delete products/services
- Update prices and images instantly
- View orders / bookings (localStorage / PHP based)
- No database required for most stores - easy cPanel hosting

**3. WhatsApp Automation:**
- Uses `https://wa.me/` API
- Auto-formatted order messages
- Custom business WhatsApp number per store
- Works with WhatsApp Business App

### Quick Start

1.  **Clone Repo:**
    ```bash
    git clone https://github.com/Evil-twist/Whatsapp-Automated-Stores.git
    cd Whatsapp-Automated-Stores
2.  *Run Any Store:*
    Just open `index.html` in a browser or use VS Code Live Server.
    For PHP features:
    php -S localhost:8000
3.  *Configure Your WhatsApp Number:*
    Open `admin panel` and edit:
    BUSINESS_WHATSAPP = "2335XXXXXXXX"; 


### Deployment

Each store can be deployed independently:

- *Free:* GitHub Pages, Netlify, Vercel
- *Pro (with admin PHP):* Hostinger, Namecheap cPanel, InfinityFree
- Just upload one business folder to your client's hosting.
